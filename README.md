### **1. Objetivo del Proyecto**

En este desarrollo del proyecto aplicaremos los respectivos conocimientos los cuales fueron adquiridos en las unidades 2 y 3 de la guía didáctica, el cual se basara en implemenatar un sitio web sobre el tema: **Impacto de las Tecnologías Web en la Sociedad y en los Negocios** con la finalidad de evidenciar el correcto uso e implementación de HTML5, aplicando estilos CSS3, integrar multimedia correctamente sobre nuestro sitio Web.

    └── contacto.html               # Formulario interactivo de comunicación y consultas.

* **index.html** Es el punto de entrada al sitio Web, en esta sección se presenta la evolución de la Web y sus diferentes etapas haciendo enfásis como se fue desarrollando el cual se presenta mediante un video explicativo.

* **sociedad.html** En esta segunda sección de la página Web abarca temas como la democratización de la información y la educación a distancia

* **negocios.html** Para esta parte contemple temas como los modelos del comerio electrónico además se adjunta una tabla comparativa en la cual se establece los mecanismos del modelo tradicional físico y el modelo digital web.

* **contacto.html** Para la parte final se incluyo una sección/ventana de buzón de contacto la misma que cuenta con sus respectivos campos para poder completar.

* **styles.css** Definimos la vista mediante CSS, en el cual estara definido el diseño en como estara organizada la información, los colores y los contenedores.

### **3. Etiquetas HTML5 utilizadas**

|Etiqueta                 |Descripción                         |
|-------------------------|------------------------------------|
| header               |Es la cabecera o franja superior que suele repetirse en todas las páginas y ofrece identidad de marca, navegación principal y accesos rápidos.| 
| nav                  |Representa una sección de una página cuyo propósito es proporcionar enlaces de navegación, ya sea dentro del documento actual o a otros documentos.|
| body                 |Contiene todo el contenido visible de una página web, como textos, títulos, imágenes, enlaces, tablas, listas y formularios.|
| main                 |Es un elemento estructural que representa el contenido principal de un documento. Es como el centro neurálgico de tu página web, que encapsula el contenido principal. Al incluir el contenido principal dentro de la etiqueta, les indica a los navegadores que esta es la información esencial que buscan los usuarios.|
| section              |Representa una sección genérica e independiente de un documento, que no tiene un elemento semántico más específico para representarla. Las secciones siempre deben tener un encabezado, con muy pocas excepciones.|
| article              |Etiqueta especifica contenido independiente y autocontenido. Un artículo debe tener sentido por sí mismo y debe poder distribuirse independientemente del resto del sitio web.|
| aside                |Representa una parte de un documento cuyo contenido está relacionado solo indirectamente con el contenido principal del documento.|
| footer               |Representa un pie de página para su antecesor más cercano, el contenido de la sección o el elemento raíz de la sección . Normalmente contiene información sobre el autor de la sección, datos de derechos de autor o enlaces a documentos relacionados.|
| h1                   |Define el encabezado principal o título más importante de una página web.|
| h3                   |Define un encabezado de tercer nivel para organizar subsecciones dentro de un tema principal.|
| ul                   |Se utiliza para crear agrupaciones de elementos que no requieren un orden numérico o secuencial específico.|
| ol                   |Representa una lista ordenada de elementos; por lo general, se muestra como una lista numerada.|
| table                |Representa datos en dos o mas dimensiones.|
| figure y img         |<figure> Representa contenido independiente, a menudo con un título. El elemento <img> de HTML incrusta una imagen en el documento.|
| iframe               |Representa un contexto de navegación anidado, el cual permite incrustrar otra página HTML en la página actual.|
| form                 |Representa una sección de un documento que contiene controles interactivos que permiten a un usuario enviar información a un servidor web.|

Permite:

* Comprobar que está bien formado el código fuente de una página de un sitio web.
* Ver el listado de errores detectados indicando la línea de código donde está situado cada uno, e indicando por qué se considera un error.
